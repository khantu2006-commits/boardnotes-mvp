Is free MVP ki real limits

  • YouTube: link alone se video frames nahi nikalte. YouTube ka cross-origin protection aur platform rules prevent direct browser extraction. Use a video file you have permission to process.
  • OCR: board ki handwriting, Hindi, diagrams aur equations mein errors ho sakte hain. PDF mein original snapshots bhi rahenge, isliye unhe verify karein.
  • Phone performance: 10–20 minute lecture ke liye 15–30 sec interval se shuru karein. Bahut saare high-resolution frames RAM/storage use karenge.
  • Internet: PDF/OCR libraries CDN se load hoti hain; first use par internet chahiye. Video frames local device par process hote hain.
